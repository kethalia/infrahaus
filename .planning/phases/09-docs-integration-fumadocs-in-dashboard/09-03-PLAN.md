# Plan 09-03: Dashboard Sidebar Integration

## Goal

Add a "Documentation" nav item to the dashboard sidebar with correct active state detection for /docs/* paths, completing the unified navigation requirement.

## must_haves
- [ ] `app-sidebar.tsx` imports `BookOpen` from `lucide-react`
- [ ] `navItems` array includes `{ title: "Documentation", href: "/docs", icon: BookOpen }`
- [ ] `isActive` logic uses `startsWith` for non-root paths so Documentation link activates on all /docs/* routes
- [ ] Existing nav items (Dashboard, Templates, Packages, Settings) are unaffected by the isActive change
- [ ] `pnpm --filter dashboard build` exits 0

## Tasks

<title>Add Documentation nav item and fix isActive in app-sidebar.tsx</title>
<file>apps/dashboard/src/components/app-sidebar.tsx</file>
<instructions>
Edit `apps/dashboard/src/components/app-sidebar.tsx` to make two changes:

**Change 1: Add `BookOpen` to the lucide-react import.**

Replace:
```tsx
import {
  LayoutDashboard,
  FileCode,
  Package2,
  Box,
  Settings,
  LogOut,
} from "lucide-react";
```

With:
```tsx
import {
  BookOpen,
  Box,
  FileCode,
  LayoutDashboard,
  LogOut,
  Package2,
  Settings,
} from "lucide-react";
```

**Change 2: Add the Documentation entry to `navItems` and update the isActive logic.**

Replace the entire `navItems` array declaration:
```tsx
const navItems = [
  {
    title: "Dashboard",
    href: "/",
    icon: LayoutDashboard,
  },
  {
    title: "Templates",
    href: "/templates",
    icon: FileCode,
  },
  {
    title: "Packages",
    href: "/templates/packages",
    icon: Package2,
  },
  {
    title: "Settings",
    href: "/settings/nodes",
    icon: Settings,
  },
];
```

With:
```tsx
const navItems = [
  {
    title: "Dashboard",
    href: "/",
    icon: LayoutDashboard,
  },
  {
    title: "Templates",
    href: "/templates",
    icon: FileCode,
  },
  {
    title: "Packages",
    href: "/templates/packages",
    icon: Package2,
  },
  {
    title: "Documentation",
    href: "/docs",
    icon: BookOpen,
  },
  {
    title: "Settings",
    href: "/settings/nodes",
    icon: Settings,
  },
];
```

**Change 3: Update the isActive calculation inside the `.map()` callback.**

Replace:
```tsx
                const isActive = pathname === item.href;
```

With:
```tsx
                const isActive =
                  item.href === "/"
                    ? pathname === "/"
                    : pathname === item.href ||
                      pathname.startsWith(item.href + "/");
```

This fix ensures:
- Dashboard `/` only matches exactly (not `/templates`, `/docs`, etc.)
- Documentation `/docs` matches `/docs` and any sub-path like `/docs/getting-started`
- Templates `/templates` matches `/templates` and `/templates/packages` — this is correct existing behavior but now explicit
- All other items match exactly or by prefix

The three changes are independent edits to the same file. Make all three changes carefully without altering any other code in the file (the header, footer, sidebar structure, logout button, etc. remain unchanged).
</instructions>
