    **1. Add RrdDataPointSchema to schemas.ts:**

    At the bottom of `apps/dashboard/src/lib/proxmox/schemas.ts`, add a new section:

    ```typescript
    // ============================================================================
    // RRD Data
    // ============================================================================

    export const RrdDataPointSchema = z.object({
      time: z.number(),
      cpu: z.number().nullable().optional(),
      maxcpu: z.number().nullable().optional(),
      mem: z.number().nullable().optional(),
      maxmem: z.number().nullable().optional(),
      disk: z.number().nullable().optional(),
      maxdisk: z.number().nullable().optional(),
      netin: z.number().nullable().optional(),
      netout: z.number().nullable().optional(),
    });
    ```

    All fields except `time` are `.nullable().optional()` because Proxmox RRD may have gaps (null values for some data points).

    **2. Add getContainerRrdData to containers.ts:**

    Import `RrdDataPointSchema` from `./schemas` and add to the existing imports. Then add this function at the bottom of the file:

    ```typescript
    /**
     * Get RRD (Round Robin Database) time-series data for a container.
     * Returns pre-aggregated metrics from Proxmox's RRD database.
     *
     * @param timeframe - "hour" (~70 points, 1-min resolution) or "day" (~70 points, ~20-min resolution)
     */
    export async function getContainerRrdData(
      client: ProxmoxClient,
      node: string,
      vmid: number,
      timeframe: "hour" | "day",
    ): Promise<z.infer<typeof RrdDataPointSchema>[]> {
      return client.get(
        `/nodes/${node}/lxc/${vmid}/rrddata?timeframe=${timeframe}`,
        z.array(RrdDataPointSchema),
      );
    }
    ```

    **3. Add RRD polling constants to timeouts.ts:**

    Add a new section at the bottom of `apps/dashboard/src/lib/constants/timeouts.ts`:

    ```typescript
    // ============================================================================
    // RRD Data Polling
    // ============================================================================

    /** RRD data staleTime for 1-hour view — data updates every ~1 minute (ms) */
    export const RRD_HOUR_STALE_TIME_MS = 60_000;

    /** RRD data staleTime for 24-hour view — data updates every ~20 minutes (ms) */
    export const RRD_DAY_STALE_TIME_MS = 5 * 60_000;
    ```

    **4. Create the RRD data API route:**

    Create `apps/dashboard/src/app/api/containers/[node]/[vmid]/rrddata/route.ts`.

    Follow the EXACT pattern from the existing `status/route.ts`:
    - Same auth pattern: `getSessionData()` → 401 if no session
    - Same node lookup: `DatabaseService.listNodesForUser(session.address)` → find by nodeName → 404 if not found
    - Same client creation: `createSessionClient(node)`
    - Parse `timeframe` from `request.nextUrl.searchParams.get("timeframe")`
    - Validate timeframe is "hour" or "day" — return 400 if invalid
    - Call `getContainerRrdData(client, nodeName, vmid, timeframe)`
    - Return `NextResponse.json(data)`
    - Catch block: log error, return 502

    The route should import:

    - `createSessionClient` from `"@/lib/containers/helpers"`
    - `getContainerRrdData` from `"@/lib/proxmox/containers"`

    Important: Do NOT add `import "server-only"` to the route — App Router route handlers are server-side by default.
