**00-pre-checks.sh** — environment validation before any installation:
- Verify running as root (`[[ $EUID -ne 0 ]]` → exit 1)
- Verify Debian 13: source /etc/os-release, check VERSION_ID="13" or VERSION_CODENAME="trixie". Exit 1 if not Debian 13 (scripts are Debian-specific).
- Check RAM (warn if < 2048MB, not error — user may be testing on minimal resources)
- Check disk space: warn if < 10GB free on /
- Check network: `curl -fsSL --max-time 5 https://deb.nodesource.com/ > /dev/null` and ping 8.8.8.8. Exit 1 if no network (all subsequent scripts need internet).
- Print system summary: OS, kernel, RAM, disk, CPUs

**01-setup-user.sh** — openclaw user configuration:
- Create user if not exists: `id openclaw 2>/dev/null` check before `useradd -m -u 1000 -s /bin/bash openclaw`
- Add to groups: `usermod -aG sudo,audio,video,render openclaw` (idempotent, usermod -aG is safe to re-run)
- Configure passwordless sudo: write `/etc/sudoers.d/openclaw` with `openclaw ALL=(ALL) NOPASSWD:ALL` (chmod 440)
- Set initial password: `echo "openclaw:openclaw" | chpasswd`
- Note: cloud-init already ran `chage -d 0 openclaw`. This script does NOT re-set chage to avoid disrupting a user who already changed their password. Only set chage if it's genuinely a fresh user creation.
- Ensure /home/openclaw has correct ownership: `chown -R openclaw:openclaw /home/openclaw`

**02-desktop-setup.sh** — XFCE desktop environment:
- `apt-get update`
- Install XFCE and display manager: `apt-get install -y task-xfce-desktop lightdm lightdm-gtk-greeter`
- Check if already installed before full reinstall: `dpkg -l task-xfce-desktop 2>/dev/null | grep -q '^ii'`
- Configure LightDM auto-login: create `/etc/lightdm/lightdm.conf.d/50-autologin.conf`:
  ```
  [Seat:*]
  autologin-user=openclaw
  autologin-user-timeout=0
  greeter-session=lightdm-gtk-greeter
  ```
- Set default target: `systemctl set-default graphical.target`
- Enable LightDM: `systemctl enable lightdm`
- Install/enable qemu-guest-agent: `apt-get install -y qemu-guest-agent && systemctl enable --now qemu-guest-agent`

**03-nodejs-setup.sh** — Node.js 22 via NodeSource:
- Idempotency check: `node --version 2>/dev/null | grep -q '^v22\.'` — skip if already v22
- Install via NodeSource: `curl -fsSL https://deb.nodesource.com/setup_22.x | bash -` then `apt-get install -y nodejs`
- Verify: `node --version` and `npm --version`
- Configure npm global prefix for openclaw user to avoid permission issues:
  ```bash
  sudo -u openclaw npm config set prefix /home/openclaw/.npm-global
  # Add to PATH in .bashrc if not already present
  grep -q 'npm-global' /home/openclaw/.bashrc || \
    echo 'export PATH="$HOME/.npm-global/bin:$PATH"' >> /home/openclaw/.bashrc
  ```

**04-chrome-install.sh** — Google Chrome via modern GPG keyring:
- Idempotency: `which google-chrome-stable 2>/dev/null` — skip if already installed
- Add GPG key (NOT deprecated apt-key):
  ```bash
  curl -fsSL https://dl.google.com/linux/linux_signing_key.pub \
    | gpg --dearmor -o /usr/share/keyrings/google-chrome.gpg
  ```
- Add repo: `echo "deb [arch=amd64 signed-by=/usr/share/keyrings/google-chrome.gpg] http://dl.google.com/linux/chrome/deb/ stable main" > /etc/apt/sources.list.d/google-chrome.list`
- Install: `apt-get update && apt-get install -y google-chrome-stable`
- Verify: `google-chrome --version`

**05-vnc-setup.sh** — TigerVNC with systemd service:
- Install: `apt-get install -y tigervnc-standalone-server tigervnc-tools`
- Set VNC password to `openclaw` for the openclaw user:
  ```bash
  sudo -u openclaw mkdir -p /home/openclaw/.vnc
  echo "openclaw" | sudo -u openclaw vncpasswd -f > /home/openclaw/.vnc/passwd
  chmod 600 /home/openclaw/.vnc/passwd
  chown openclaw:openclaw /home/openclaw/.vnc/passwd
  ```
- Create `/home/openclaw/.vnc/xstartup`:
  ```bash
  #!/bin/sh
  unset SESSION_MANAGER
  unset DBUS_SESSION_BUS_ADDRESS
  exec startxfce4
  ```
  `chmod +x /home/openclaw/.vnc/xstartup && chown openclaw:openclaw /home/openclaw/.vnc/xstartup`
- Create systemd template unit `/etc/systemd/system/vncserver@.service`:
  ```ini
  [Unit]
  Description=TigerVNC server on display :%i
  After=syslog.target network.target

  [Service]
  Type=forking
  User=openclaw
  Group=openclaw
  WorkingDirectory=/home/openclaw
  ExecStartPre=-/usr/bin/vncserver -kill :%i > /dev/null 2>&1 || true
  ExecStart=/usr/bin/vncserver -depth 24 -geometry 1920x1080 -localhost no :%i
  ExecStop=/usr/bin/vncserver -kill :%i

  [Install]
  WantedBy=multi-user.target
  ```
  CRITICAL: `-localhost no` is required for remote VNC clients to connect. Without it, VNC only accepts connections from localhost.
- `systemctl daemon-reload && systemctl enable vncserver@1`
- Verify unit exists and is enabled: `systemctl is-enabled vncserver@1`

**06-openclaw-install.sh** — Defensive OpenClaw install:
This script MUST check whether openclaw exists on the npm registry BEFORE attempting to install it. If the package is not found, it must print a clear error with actionable next steps instead of leaving the user with a confusing npm error.

```bash
#!/usr/bin/env bash
set -euo pipefail

# [color helpers as above]

info "Checking npm registry for openclaw package..."

# Check if openclaw exists on npm registry before attempting install.
# openclaw may not be a public npm package. This check prevents a confusing
# npm ERR! 404 and provides a clear error message with instructions.
if ! npm view openclaw version >/dev/null 2>&1; then
  error "openclaw package not found on npm registry (npm view openclaw version failed)."
  echo ""
  echo "This means openclaw is not published to the public npm registry."
  echo ""
  echo "TODO: Update this script with the correct installation method:"
  echo "  - Check the OpenClaw repository for install instructions"
  echo "  - Possible alternatives:"
  echo "      npm install -g @<org>/openclaw@latest"
  echo "      npx openclaw"
  echo "      Download binary from GitHub releases"
  echo ""
  echo "Once you know the correct source, edit this script and re-run:"
  echo "  ./run-scripts.sh <VM_IP> 06-openclaw-install.sh"
  echo ""
  # Exit 1 so run-scripts.sh knows this script failed and offers to continue/abort
  exit 1
fi

# Package exists on npm — proceed with global install
info "Installing openclaw globally..."
npm install -g openclaw@latest

# Verify
if openclaw --version 2>/dev/null; then
  info "openclaw installed successfully"
elif which openclaw 2>/dev/null; then
  info "openclaw binary found at: $(which openclaw)"
else
  error "openclaw install appeared to succeed but 'openclaw' command not found."
  echo "Ensure /home/openclaw/.npm-global/bin is in PATH (run 03-nodejs-setup.sh first)."
  exit 1
fi
```
