# Plan 10-01: Migrate MDX Files

## Goal

Copy all 29 MDX files and 10 meta.json files from `apps/web/content/docs/` into `apps/dashboard/content/docs/`, replacing the Phase 09 placeholder `index.mdx` with the real one from apps/web and creating the full 9-section directory structure.

## must_haves

- [ ] All 39 files (29 MDX + 10 meta.json) present in `apps/dashboard/content/docs/`
- [ ] `diff -rq apps/web/content/docs apps/dashboard/content/docs` returns empty output (byte-identical copies)
- [ ] No MDX frontmatter modified — title and description fields preserved as-is
- [ ] All 9 section subdirectories exist: getting-started, container-templates, ai, development, deployment, media, gaming, blockchain, networking
- [ ] Root `meta.json` present at `apps/dashboard/content/docs/meta.json`

## Tasks

<task id="10-01-01">
<title>Copy all docs content from apps/web to apps/dashboard</title>
<instructions>
Run the following command from the monorepo root to copy all MDX and meta.json files from the source tree into the dashboard content directory. The `-r` flag copies recursively. The trailing `.` on the source path copies directory contents (not the directory itself), so files land directly under `apps/dashboard/content/docs/`. This overwrites the existing placeholder `index.mdx`.

```bash
cp -r apps/web/content/docs/. apps/dashboard/content/docs/
```

After running, verify the file count equals 39:

```bash
find apps/dashboard/content/docs -type f | wc -l
```

Expected output: `39`
</instructions>
<automated>
find apps/dashboard/content/docs -type f | wc -l
</automated>
</task>

<task id="10-01-02">
<title>Verify byte-identical copy with diff</title>
<instructions>
Run a recursive diff between source and destination to confirm all files were copied without modification:

```bash
diff -rq apps/web/content/docs apps/dashboard/content/docs
```

Expected output: empty (no differences). Any output indicates a mismatch that must be resolved before proceeding.
</instructions>

</task>
