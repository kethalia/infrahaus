# Plan 13-01: Infra Inventory + LXC Template Definitions

## Goal

Create `template.conf` files and install scripts for the two LXC-deployable infra services (Dokploy and WireGuard Proxy) so they are automatically discovered by the existing template engine and appear on the `/templates` page.

> **Out of scope:** An Ollama LXC template is explicitly excluded from this phase. Ollama CPU-only inference is cataloged as a docker-compose service in Plan 13-02 (`id: "ollama-standalone"`). An LXC-specific Ollama template (for bare-metal CPU use cases) is deferred to a future phase.

## must_haves

- [ ] `infra/lxc/templates/dokploy/template.conf` exists with all required fields (TEMPLATE_APP, TEMPLATE_TAGS, TEMPLATE_CPU, TEMPLATE_RAM, TEMPLATE_DISK, TEMPLATE_OS, TEMPLATE_VERSION, TEMPLATE_UNPRIVILEGED, TEMPLATE_NESTING, TEMPLATE_KEYCTL, TEMPLATE_FUSE)
- [ ] `infra/lxc/templates/wireguard-proxy/template.conf` exists with all required fields
- [ ] Each template has a `container-configs/scripts/` directory with numbered shell scripts (00-, 01-, 02-) following the same pattern as `infra/lxc/templates/web3-dev/`
- [ ] Each template has a `container-configs/packages/base.apt` listing required packages
- [ ] `pnpm --filter dashboard exec tsc --noEmit` exits 0 (no dashboard code changes are introduced that could break types)
- [ ] Running `discoverTemplatesAction` (via the "Discover Templates" button in the UI) upserts both new templates into the database without errors

## Tasks

<task id="13-01-01" title="Create Dokploy LXC template.conf">
<context>The discovery engine scans `infra/lxc/templates/` for directories containing `template.conf`. Adding a `dokploy/template.conf` with the correct bash key=value format is all that is needed for the engine to pick it up. Dokploy requires Docker Swarm, so nesting=1 and unprivileged=1. Minimum resources: 2 CPU, 2GB RAM, 20GB disk. The `web3-dev/template.conf` is the canonical format reference.</context>
<steps>
1. Create directory `infra/lxc/templates/dokploy/`
2. Create `infra/lxc/templates/dokploy/template.conf` with the following content:
   ```bash
   #!/usr/bin/env bash
   # Dokploy LXC Template Configuration

   TEMPLATE_APP="Dokploy"
   TEMPLATE_TAGS="deployment;docker;swarm;paas;infra"
   TEMPLATE_DESCRIPTION="Self-hosted PaaS with Docker Swarm, Traefik, Postgres, and Redis"
   TEMPLATE_CONFIG_PATH="infra/lxc/templates/dokploy/container-configs"
   TEMPLATE_CPU="${TEMPLATE_CPU:-2}"
   TEMPLATE_RAM="${TEMPLATE_RAM:-2048}"
   TEMPLATE_DISK="${TEMPLATE_DISK:-20}"
   TEMPLATE_OS="${TEMPLATE_OS:-debian}"
   TEMPLATE_VERSION="${TEMPLATE_VERSION:-12}"
   TEMPLATE_UNPRIVILEGED="${TEMPLATE_UNPRIVILEGED:-1}"
   TEMPLATE_NESTING="${TEMPLATE_NESTING:-1}"
   TEMPLATE_KEYCTL="${TEMPLATE_KEYCTL:-0}"
   TEMPLATE_FUSE="${TEMPLATE_FUSE:-0}"
   ```
3. Verify the file matches the key=value bash format used by `infra/lxc/templates/web3-dev/template.conf`
</steps>
<automated>
`test -f infra/lxc/templates/dokploy/template.conf && grep -q 'TEMPLATE_APP="Dokploy"' infra/lxc/templates/dokploy/template.conf && echo "OK"`
</automated>
</task>

<task id="13-01-02" title="Create Dokploy LXC install scripts">
<context>The template engine reads `container-configs/scripts/` for numbered `*.sh` files. Three scripts are needed: pre-checks (identical pattern to web3-dev's 00-pre-checks.sh), Docker install (identical to web3-dev's 02-docker-install.sh — reuse the script content exactly), and a Dokploy-specific install script that runs the logic from `infra/dokploy/install.sh`. The scripts use `log_info`, `log_warn`, `log_error`, `is_installed`, `ensure_installed`, and `wait_for_apt_lock` helpers provided by the forge-shield runner environment.</context>
<steps>
1. Create directory `infra/lxc/templates/dokploy/container-configs/scripts/`
2. Create `00-pre-checks.sh` — copy the content of `infra/lxc/templates/web3-dev/container-configs/scripts/00-pre-checks.sh` verbatim, then update the header comment to reference Dokploy and change the memory check threshold to 2048 MB
3. Create `01-docker-install.sh` — copy the content of `infra/lxc/templates/web3-dev/container-configs/scripts/02-docker-install.sh` verbatim (Docker CE install is identical regardless of template)
4. Create `02-dokploy-install.sh` with `set -euo pipefail`, using `log_info`/`log_error` helpers. Script must: check Docker is running, check ports 80 and 443 are free (`ss -tulnp`), run `docker swarm init` if not already initialized, pull images via `docker compose -f /opt/dokploy/docker-compose.yaml up -d`, and log the Dokploy URL at the end. The compose file path should be `/opt/dokploy/docker-compose.yaml` (copied into the container during provisioning).
5. Make all three scripts executable: `chmod +x` on each
</steps>
<automated>
`ls infra/lxc/templates/dokploy/container-configs/scripts/ | sort`
</automated>
</task>

<task id="13-01-03" title="Create Dokploy package list and compose file">
<context>The template engine reads `container-configs/packages/*.apt` files for apt package lists. A base.apt file ensures the container has necessary system packages before the Docker install script runs. The Dokploy compose file needs to be available inside the container at `/opt/dokploy/docker-compose.yaml`; placing it under `container-configs/files/` allows forge-shield to copy it during provisioning.</context>
<steps>
1. Create directory `infra/lxc/templates/dokploy/container-configs/packages/`
2. Create `infra/lxc/templates/dokploy/container-configs/packages/base.apt` with content:
   ```
   curl
   ca-certificates
   gnupg
   iproute2
   ```
3. Create directory `infra/lxc/templates/dokploy/container-configs/files/`
4. Create `infra/lxc/templates/dokploy/container-configs/files/opt/dokploy/docker-compose.yaml` — copy the content of `infra/dokploy/docker-compose.yaml` verbatim
5. Create `infra/lxc/templates/dokploy/container-configs/files/opt/dokploy/docker-compose.yaml.path` containing `/opt/dokploy/docker-compose.yaml`
6. Create `infra/lxc/templates/dokploy/container-configs/files/opt/dokploy/docker-compose.yaml.policy` containing `copy`
</steps>
<automated>
`test -f infra/lxc/templates/dokploy/container-configs/packages/base.apt && echo "OK"`
</automated>
</task>

<task id="13-01-04" title="Create WireGuard Proxy LXC template.conf">
<context>WireGuard + Nginx Proxy Manager can run in a privileged LXC with network capabilities. This is a useful networking template for the dashboard. Resources: 1 CPU, 512MB RAM, 8GB disk. Unprivileged=0 because WireGuard kernel module access requires a privileged container. Nesting=1 to allow Docker.</context>
<steps>
1. Create directory `infra/lxc/templates/wireguard-proxy/`
2. Create `infra/lxc/templates/wireguard-proxy/template.conf` with the following content:
   ```bash
   #!/usr/bin/env bash
   # WireGuard Proxy LXC Template Configuration

   TEMPLATE_APP="WireGuard Proxy"
   TEMPLATE_TAGS="networking;wireguard;proxy;nginx;infra"
   TEMPLATE_DESCRIPTION="WireGuard VPN with Nginx Proxy Manager for reverse proxy and SSL"
   TEMPLATE_CONFIG_PATH="infra/lxc/templates/wireguard-proxy/container-configs"
   TEMPLATE_CPU="${TEMPLATE_CPU:-1}"
   TEMPLATE_RAM="${TEMPLATE_RAM:-512}"
   TEMPLATE_DISK="${TEMPLATE_DISK:-8}"
   TEMPLATE_OS="${TEMPLATE_OS:-debian}"
   TEMPLATE_VERSION="${TEMPLATE_VERSION:-12}"
   TEMPLATE_UNPRIVILEGED="${TEMPLATE_UNPRIVILEGED:-0}"
   TEMPLATE_NESTING="${TEMPLATE_NESTING:-1}"
   TEMPLATE_KEYCTL="${TEMPLATE_KEYCTL:-0}"
   TEMPLATE_FUSE="${TEMPLATE_FUSE:-0}"
   ```
3. Verify the file parses correctly with the same bash key=value format
</steps>
<automated>
`test -f infra/lxc/templates/wireguard-proxy/template.conf && grep -q 'TEMPLATE_APP="WireGuard Proxy"' infra/lxc/templates/wireguard-proxy/template.conf && echo "OK"`
</automated>
</task>

<task id="13-01-05" title="Create WireGuard Proxy LXC install scripts and packages">
<context>WireGuard Proxy needs the same three-script pattern: pre-checks, Docker install, and a WireGuard-specific setup script. The WireGuard compose file from `infra/wireguard/docker-compose.yaml` runs Nginx Proxy Manager alongside a WireGuard container.</context>
<steps>
1. Create directory `infra/lxc/templates/wireguard-proxy/container-configs/scripts/`
2. Create `00-pre-checks.sh` — copy from `infra/lxc/templates/web3-dev/container-configs/scripts/00-pre-checks.sh` and update the header comment and memory threshold to 512 MB
3. Create `01-docker-install.sh` — copy from `infra/lxc/templates/web3-dev/container-configs/scripts/02-docker-install.sh` verbatim
4. Create `02-wireguard-install.sh` with `set -euo pipefail`, using the forge-shield log helpers. Script must: load the wireguard kernel module (`modprobe wireguard`), verify the module loaded, run `docker compose -f /opt/wireguard-proxy/docker-compose.yaml up -d`, and log the Nginx Proxy Manager admin URL (port 81)
5. Create directory `infra/lxc/templates/wireguard-proxy/container-configs/packages/`
6. Create `infra/lxc/templates/wireguard-proxy/container-configs/packages/base.apt` with content:
   ```
   curl
   ca-certificates
   gnupg
   iproute2
   wireguard-tools
   ```
7. Create directory `infra/lxc/templates/wireguard-proxy/container-configs/files/opt/wireguard-proxy/`
8. Copy `infra/wireguard/docker-compose.yaml` content into `infra/lxc/templates/wireguard-proxy/container-configs/files/opt/wireguard-proxy/docker-compose.yaml`
9. Create `.path` file containing `/opt/wireguard-proxy/docker-compose.yaml` and `.policy` file containing `copy` alongside it
10. Make all scripts executable
</steps>
<automated>
`ls infra/lxc/templates/wireguard-proxy/container-configs/scripts/ | sort`
</automated>
</task>

```bash
grep -l TEMPLATE_APP infra/lxc/templates/dokploy/template.conf infra/lxc/templates/wireguard-proxy/template.conf

for key in TEMPLATE_APP TEMPLATE_TAGS TEMPLATE_CPU TEMPLATE_RAM TEMPLATE_DISK TEMPLATE_OS TEMPLATE_VERSION TEMPLATE_UNPRIVILEGED TEMPLATE_NESTING TEMPLATE_KEYCTL TEMPLATE_FUSE; do
  grep -q "$key" infra/lxc/templates/dokploy/template.conf && echo "$key: OK" || echo "$key: MISSING"
done

# Verify all required keys are present in wireguard-proxy template
for key in TEMPLATE_APP TEMPLATE_TAGS TEMPLATE_CPU TEMPLATE_RAM TEMPLATE_DISK TEMPLATE_OS TEMPLATE_VERSION TEMPLATE_UNPRIVILEGED TEMPLATE_NESTING TEMPLATE_KEYCTL TEMPLATE_FUSE; do
  grep -q "$key" infra/lxc/templates/wireguard-proxy/template.conf && echo "$key: OK" || echo "$key: MISSING"
done

# Verify scripts are present
ls infra/lxc/templates/dokploy/container-configs/scripts/
ls infra/lxc/templates/wireguard-proxy/container-configs/scripts/

# Type check (no dashboard code changes, should exit 0)
pnpm --filter dashboard exec tsc --noEmit
```
