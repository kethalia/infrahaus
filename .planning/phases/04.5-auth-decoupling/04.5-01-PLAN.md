**Update `apps/dashboard/src/lib/constants/infrastructure.ts`:**
- Add `MAX_SESSION_TTL_S = 86_400` (24 hours) — server-enforced maximum session TTL regardless of what the SIWE message requests
- Add `DEFAULT_SESSION_TTL_S = 7_200` (2 hours) — fallback if SIWE message has no expirationTime
- Keep existing `SESSION_TTL` constant (rename to `SESSION_TTL` is fine, or leave if other code uses it — the new constants are used by the rewritten createSession)

**Rewrite `apps/dashboard/src/lib/session.ts`:**

1. **Remove** `import type { ProxmoxTicketCredentials } from "@/lib/proxmox/types"` — no longer needed
2. **Remove** the entire `getProxmoxCredentials()` function (lines 190-204)
3. **Update `SessionData` interface** (iron-session cookie shape):
   ```typescript
   export interface SessionData {
     sessionId?: string;
     nonce?: string; // Temporary SIWE nonce (set during /api/auth/nonce, consumed by /api/auth/verify)
   }
   ```
4. **Replace `RedisSessionData` interface** entirely:
   ```typescript
   export interface RedisSessionData {
     address: string;      // Universal Profile address (0x...)
     signature: string;    // SIWE signature
     message: string;      // Raw SIWE message string
     messageHash: string;  // keccak256 of the SIWE message
     expiresAt: string;    // ISO date string — derived from SIWE expirationTime
   }
   ```
5. **Update `createSession()` function:**
   - Change parameter type to accept `{ address, signature, message, messageHash, expiresAt }` (matching new RedisSessionData)
   - Compute dynamic TTL from expiresAt: `Math.min(Math.floor((new Date(data.expiresAt).getTime() - Date.now()) / 1000), MAX_SESSION_TTL_S)`
   - If computed TTL is ≤ 0, use `DEFAULT_SESSION_TTL_S`
   - Store session data in Redis with computed TTL via `redis.setex()`
   - Import `MAX_SESSION_TTL_S`, `DEFAULT_SESSION_TTL_S` from constants
6. **Update `getSessionData()` function:**
   - Return type stays `Promise<RedisSessionData | null>` (but the interface changed)
   - Parse logic stays the same (read from Redis, check expiry)
   - No other functional changes needed
7. **Keep** `getSession()` and `destroySession()` unchanged — they work with cookie/Redis generically
8. **Keep** `"server-only"` import at top
9. **Update** the `SESSION_TTL` reference in createSession to use the new dynamic TTL computation (don't use the old fixed constant)
  </action>
